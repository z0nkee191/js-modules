# Практична робота: Події клавіатури та бібліотека Chart.js

Цей репозиторій містить виконання двох навчальних завдань з JavaScript:
1. **Завдання 1: Гра «Натисни правильну клавішу»** — робота з подіями клавіатури (keydown, keypress) та виведення повідомлень за допомогою бібліотеки PNotify v5.
2. **Завдання 2: Графік продажів** — побудова лінійного адаптивного графіка за допомогою бібліотеки Chart.js v4.

---

## Структура проєкту

```text
js-modules/
├── index.html            # Головний HTML-документ (розмітка та підключення CDN-бібліотек)
├── README.md             # Опис проєкту та інструкції
└── src/
    ├── css/
    │   └── styles.css    # Стилізація інтерфейсу, карток та візуальної клавіші
    └── js/
        ├── task-1.js     # Логіка гри "Натисни правильну клавішу"
        └── task-2.js     # Конфігурація та рендеринг графіка Chart.js
```

---

## Як запустити проєкт

1. Відкрийте файл index.html у будь-якому сучасному веббраузері (або запустіть за допомогою розширення Live Server у VS Code).
2. Для роботи бібліотек потрібне підключення до Інтернету (бібліотеки Chart.js та PNotify завантажуються через офіційні CDN jsDelivr).

---

## Використані бібліотеки

- [Chart.js v4](https://www.chartjs.org/) — для побудови адаптивних графіків та діаграм.
- [PNotify v5](https://github.com/sciactive/pnotify) (разом з BrightTheme) — для спливаючих сповіщень.
